# Multi-Class Benchmark Classification Pipeline

## Project Overview
This project implements a multi-class machine learning classification pipeline using the Iris dataset. The objective is to classify Iris flowers into three different species based on their physical measurements.

## Dataset Information
- Dataset: Iris Dataset
- Total Samples: 150
- Total Features: 4
- Target Classes: Setosa, Versicolor, Virginica

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier

## Project Workflow
1. Dataset Loading
2. Exploratory Data Analysis
3. Data Visualization
4. Feature Selection
5. Train-Test Split (80:20)
6. Feature Scaling using StandardScaler
7. Model Training
8. Model Evaluation
9. Confusion Matrix Visualization
10. Model Performance Comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Conclusion
Both classification algorithms were trained and evaluated. Their performance was compared using multiple evaluation metrics to identify the better-performing model.
